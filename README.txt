SOUL SURVIVOR: ANIME — bản prototype 2D ngang

Chơi thử:
- Giải nén ZIP.
- Mở index.html trên máy tính để thử.
- Trên Android, để cài như PWA cần tải thư mục này lên một máy chủ HTTPS (ví dụ GitHub Pages hoặc Netlify), sau đó mở URL bằng Chrome và chọn "Cài đặt ứng dụng" / "Thêm vào màn hình chính".
- PWA cần HTTPS; mở file trực tiếp từ bộ nhớ điện thoại sẽ không cài được offline đúng cách.

Điều khiển:
- Joystick bên trái để di chuyển.
- Nút TỰ ĐÁNH bên phải để tung kiếm khí; nhân vật cũng tự động tấn công mục tiêu gần nhất.
- Nút II để tạm dừng.
- Hạ quái, nhặt linh hồn, lên cấp và chọn nâng cấp.

Đây là bản prototype chạy bằng HTML Canvas, chưa phải APK Android độc lập. Có thể đóng gói thành APK sau khi triển khai và kiểm thử trên thiết bị.
